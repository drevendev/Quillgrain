# Редакторский список и техническое покрытие

`qg check` сохраняет прежний `quillgrain.check-report/v1`. Findings относятся
к исполнимым ограничениям; `HUMAN_REVIEW_REQUIRED` не означает выполненную
редакторскую проверку. CLI отдельно выводит `coverage`: исполненные правила,
правила для человеческого решения и недоступные character scopes. Отсутствие
механического покрытия обозначается `NONE`; качество голоса не измеряется.

По явному локальному запросу можно получить список редакторской работы:

```text
qg check --draft DRAFT.md --context CONTEXT.json --out CHECK.json --review-json NEW_REVIEW.json --review-md NEW_REVIEW.md
```

Оба дополнительных файла должны быть новыми. Совпадение выходов друг с другом
или входными файлами отвергается. Черновик и контекст не изменяются.
Для полностью редакторского профиля этот явный экспорт допустим, хотя обычному
письму не нужен пустой обязательный запуск checker.

`quillgrain.editorial-review/v1` содержит `context_build_id`, `draft_sha256`
и `items`. У пункта есть `rule_id`, исходная `instruction`, выбранные `language`,
`register`, `tags`, исходный `scope`, `applicability` и `status: NOT_REVIEWED`.
Неизвестная разметка персонажа даёт `CHARACTER_SCOPE_UNAVAILABLE`. Берутся только
уже применённые `human_review` правила; отброшенные при composition или по
бюджету правила не возвращаются. Экспорт одинаковых входов воспроизводим.

Сначала reviewer читает целый текст, затем использует список для конкретных
замечаний. Отдельная заметка может иметь такой формат:

```text
rule_id: synthetic.clarity
draft_sha256: SHA256_OF_REVIEWED_DRAFT
span_or_quote: конкретное место в черновике
category: fact_or_brief | language_norm | register_audience_speaker | taste
observation: что замечено
reason_and_loss: почему это мешает в данном контексте
alternative: необязательный вариант
current_norm_source: источник, если заявлена современная языковая норма
decision: NOT_REVIEWED | KEEP | REVISE | UNDETERMINED
```

Заметка не меняет исходный текст или значения check-report. Другой допустимый
вариант формулировки не объявляется исправлением ошибки. Норма, частота,
историческая рекомендация и личный вкус имеют разные основания. Неотвеченный
пункт остаётся неизвестным. Список не является PASS, оценкой сходства с автором
или разрешением публикации; содержимое pack не экспортируется публично автоматически.

Явный word budget проверяется отдельным `qg-words/v1`, включая части и сумму.
Полностью редакторский профиль не отменяет численное ограничение задания.
