# Ink Duel: локальная редакторская оценка

## Парная версия v2

Новый протокол существует отдельно от старого: 30 исходников по 80–120 слов,
пять категорий (`lanterra`, `frontier`, `news`, `denis`, `classics`), по шесть работ.
Для каждой категории шесть разных пар четырёх условий. В каждом раунде два
варианта одного исходника; каждое условие появляется 15 раз за кампанию.
Стороны сбалансированы: 1/2 появления слева в категории, 7/8 за всю кампанию.
Назначение пары исходнику замораживается по seed до просмотра результатов.
Анонимные A/B/C/D перемешиваются отдельно для каждого исходника.

```text
python scripts/pair_demo.py --out NEW_SYNTHETIC_DEMO
qg duel pair-prepare --cases CASES_V2.json --reference-works REFERENCE_WORK_IDS.json --out NEW_SESSION --order-seed INTEGER --mapping-seed INTEGER
qg duel serve --session NEW_SESSION/blind-session.json --port 8768
qg duel pair-reveal --session NEW_SESSION/blind-session.json --answers ANSWERS_V2.json --key NEW_SESSION/answer-key.private.json --out NEW_REVEAL
```

Демонстрация содержит только вымышленные MOCK-варианты; она проверяет интерфейс,
а не качество модели или материалы пяти настоящих категорий. Для реального
набора нужны LIVE-свидетельства, проверка прав, редакторский аудит, замороженные
входы и отдельный список идентификаторов работ из референсного корпуса.
Совпадение работ с этим списком отклоняется. Одинаковые ID работ должны
использоваться последовательно; проверка не распознаёт псевдонимы произведений.
Генерируются все четыре варианта: 120 подготовленных текстов, 60 показанных.

Если для блоговой категории нет разрешения правообладателя, оператор может
явно выбрать замену `--blog-category techprose` при `pair-prepare`. Тогда нужны
шесть разрешённых исходников с группой `techprose`; остальные четыре категории
и баланс пар сохраняются. Без этого флага действует прежняя группа `denis`.
В ключе и отчёте сохраняется фактическая категория; смешанный набор из шести
категорий отклоняется. Сам флаг не подтверждает права на переданные тексты.

Смысловые данные — короткие слоты «кто / отношение / значение / степень
уверенности», каждый с подтверждающим фрагментом исходника и редакторской
проверкой. В модельном задании они явно названы границами содержания, а не
фразами для вставки. `generation_prompt` одинаков для трёх модельных условий;
стилевой контекст добавляется отдельно. Проверка наличия подтверждающей цитаты
не доказывает верность её интерпретации. Реальные запросы и ответы записывает
оператор вне репозитория; этот модуль не запускает модель.

На одной странице: два текста, пять критериев и необязательная похожесть на
автора. Ответы категориальные: левый / равно / правый / не могу оценить,
без ответа по умолчанию. Две необязательные догадки независимы; можно выбрать
одну роль для обоих текстов. Один переход сохраняет раунд; черновик сохраняется
после каждого изменения. Есть локальное хранение, JSON-импорт/экспорт,
перечитывание сохранённых раундов и отдельное раскрытие после 30 раундов.

Дословно одинаковым текстам нельзя назначить однозначную победу. Их равенство
отмечается отдельно как неразличимость; догадки исключаются из знаменателя
узнавания. Отчёт считает победы, ничьи, поражения, пропуски и неразличимые пары
по каждому критерию, группе и паре условий. Похожесть не смешивается с качеством.
Старые числовые оценки не пересчитываются в победы.

Разные пары проверяются на разных исходниках: это предварительное сравнение,
а не все пары на каждом тексте. Для последнего понадобилось бы 180 раундов.
Сервер сам выбирает клиент v1 или v2 по версии набора. Старые кампании, файлы
ответов и адрес прежней игры продолжают работать отдельно.

Проверки нового режима:

```text
python -m pytest tests/test_pairwise.py
node --test tests/pair_client.test.cjs
```

## Прежняя числовая версия v1

Клиент показывает 20 замороженных заданий по четыре коротких варианта. Он не
вызывает модель во время игры. Настоящие исходники, личные профили, модельные
записи, ключи и оценки хранятся вне репозитория. В тестах только вымышленные тексты.

```text
qg duel prepare --cases CASES.json --out NEW_SESSION --order-seed INTEGER --mapping-seed INTEGER
qg duel serve --session NEW_SESSION/blind-session.json --port 8767
qg duel reveal --session NEW_SESSION/blind-session.json --answers ANSWERS.json --key NEW_SESSION/answer-key.private.json --out NEW_REVEAL
```

Это операторские действия. Флаг `--synthetic` в `prepare` допускает только MOCK
записи и явно помечает пример. Обычный режим требует LIVE-свидетельств и завершённой
редакторской проверки. Статус LIVE — запись предоставленных доказательств, не
независимое доказательство происхождения текста или правильности лицензии.

Квоты: четыре группы по пять отдельных работ. Один раунд — исходник, обычная
модельная переработка без стилевого пакета, Common и выбранный профиль. ORIGINAL
не означает ни хорошего текста, ни подтверждённого человеческого авторства.
Три модельных условия используют одинаковое содержание, модель, параметры и seed.
Реальные данные и права проверяет оператор до создания игрового файла.

Пять осей: живость, естественность, понятность, лаконичность и точность смысла.
Для последней допустимо «не могу оценить». Оценки фиксируются до вопросов
о предпочтении и происхождении. Раунд после фиксации доступен только для чтения.
Метки сохраняются при перезагрузке. После десяти заданий — перерыв без раскрытия;
после двадцати — экспорт ответов и отдельный импорт раскрытия.

Хранилище браузера содержит оценки/заметки и непрозрачные ID, но не сами карточки
и не ключ. Его можно отключить; тогда нужен экспорт прогресса. При отказе хранилища
интерфейс показывает предупреждение. Экспорт может содержать выбранные пользователем
цитаты: это локальный файл, не предназначенный для автоматической публикации.

Сервер слушает только 127.0.0.1. Он раздаёт три файла клиента и один замаскированный
набор; ключ, родительские папки и любые другие маршруты недоступны. Код клиента
можно также открыть локально и загрузить JSON через выбор файла. Нет CDN и телеметрии.

Ослепление процедурное. Знакомый отрывок может выдать исходник; участник отмечает
узнавание. Не заявляется защита от владельца компьютера, изучающего собственные файлы.
Хэши выявляют несогласованность, но не удостоверяют независимое авторство.

Отчёт показывает пять отдельных шкал с количеством оценок, средним, медианой и
распределением, парные различия, предпочтения, пропуски и матрицу догадок.
Естественность не является детектором ИИ. Результаты одного оценщика и одной модели
не подтверждают универсальное качество и не утверждают авторский профиль.

## Проверки разработки

```text
python -m pytest
node --test tests/duel_client.test.cjs
```

Дополнительно проверить клиент в настоящем браузере: все 20 раундов, блок 10/10,
reload, импорт/экспорт, ошибочный файл, ручное раскрытие, клавиатура и узкий экран.
Перед публикацией кода проверить фактический source/wheel/sdist на отсутствие
реальных источников, ключей, личных результатов и локальных путей.
