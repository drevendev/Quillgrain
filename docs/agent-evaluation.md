# Приёмка skills в агенте

Этот слой проверяет выбор и исполнение skill. Ink Duel оценивает показанные
тексты и не проверяет discovery, references или запуск bundled scripts.
Исходные запросы и ожидаемые действия находятся в
[agent-evals.json](../examples/synthetic/agent-evals.json).

Три начальных семейства — новая сцена с бюджетом, ограниченная правка исходника
и перенос без установленного engine. Вариации охватывают явный и автоматический
вызов, неподходящий запрос, другой голос, отсутствующий pack, запрещённый host,
язык/регистр и совпадение имён. Расширение набора следует наблюдаемым провалам,
а не полному произведению всех комбинаций.

Для каждого запуска локально сохраняются поверхность и версия клиента,
фактические model/effort либо `UNKNOWN`, инструменты, ограничения изоляции,
прочитанные skill/context, выполненные команды, исходник и результат с hash,
проверка бюджета и конкретные отказы. Отдельные решения относятся к routing,
механическому выполнению и качеству прозы. Дословное совпадение ответа с шаблоном
не заменяет проверку артефакта.

Для оценки пользы стиля сравниваются одинаковые задания без skill, с короткой
обычной инструкцией и с полным skill. Сами эти сравнения не запускаются CI.
Приватные журналы и реальные writer outputs хранятся вне публичного checkout.
Публичные автоматические проверки используют синтетические данные.

## Результаты проверки 15 ноября 2026 года

| Поверхность | Наблюдение | Предел результата |
| --- | --- | --- |
| Codex CLI | Явно выбран проектный синтетический skill; прочитаны его instructions/context и brief. При отказе исполнения агент сообщил `NOT_RUN` | Вложенная Windows-среда запретила команды помощников и запись draft. Полная механическая приёмка в агенте не пройдена |
| Claude Code CLI 2.1.259 | Клиент был вызван на отдельном синтетическом проекте | OAuth-сессия истекла и не обновилась; проверка поведения `NOT_RUN` |
| Переносимый помощник | Изолированный Python с `-I -S`, без site packages, выполняет перенесённый helper; tamper/host/lock/lineage векторы проверены | Это техническая приёмка helper, а не модельного выбора |
| Совпадения user/project | Два синтетических профиля проверяют диагностику и сохранность установок | Фактический выбор агента при одноимённых профилях остаётся `NOT_RUN` |
| Автоматический выбор и три prose controls | Подготовлены сценарии и формат наблюдений | Реальные сравнения не проводились |

Ограничения среды не снимаются отключением защит. Для завершения live-приёмки
нужны действующая авторизация и среда, разрешающая обычные локальные операции
по задаче. Затем выполняются сценарии на каждой заявленной поверхности.
Проверка Codex CLI не подтверждает Codex desktop, Claude Code или claude.ai.

Контракты локальных skills сверены с
[Agent Skills Specification](https://agentskills.io/specification),
[документацией Codex](https://learn.chatgpt.com/docs/build-skills)
и [Claude Code](https://code.claude.com/docs/en/skills).
Эти источники описывают формат и discovery; они не являются результатами
поведенческого теста Quillgrain.
