# Проверка правила на вмешательство и сохранение

Цель протокола — обнаружить как полезную правку, так и вред чрезмерного
применения правила. Исходный набор находится в
[editorial-regression.json](../examples/synthetic/editorial-regression.json).
Это оригинальные синтетические задания, без книжных пассажей или ответов модели.
Поведенческий результат набора остаётся `NOT_RUN` до фактического опыта.

Для каждого правила заранее фиксируются случай необходимого вмешательства,
близкий случай сохранения того же языкового признака, смысловая граница,
допустимые альтернативы и неопределённые решения. Набор содержит три семейства:
термин/служебная конструкция, понятное/непрозрачное сокращение и обычная идиома/
случайная порча/намеренная переделка. В одном семействе общий источник контраста;
семь вариантов не становятся семью независимыми доказательствами переноса.

1. Выбрать конкретные предыдущий и кандидатный контексты с digest и режимом
   примеров. Заморозить задания, writer, reasoning, объём и независимость запросов.
2. Использовать существующие eval-пакеты и запись сырых ответов. Сохранять все
   попытки и технические исключения; не заменять ответ скрытой редактурой.
3. Для каждого ответа раздельно записать нарушение смысла, лишнее вмешательство,
   допустимую вариативность или неопределённость. Сохранение уместного выражения
   является успешным исходом.
4. На development-наборе уточнить правило, затем зафиксировать кандидата и взять
   новый разрешённый reserve-материал. Разобранный пример не является holdout.

Ожидания заданы смысловыми свойствами. Ответ не должен дословно совпасть
с образцом; уменьшение числа слов и удаление всех триггерных выражений
не считаются целью. Протокол не увеличивает бюджет обязательной Ink Duel.
Измерения выполняет Scriptorium, а литературное решение сохраняется отдельно.
