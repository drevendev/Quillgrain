# Repository instructions

This is the public engine. Use only original synthetic fixtures in tests and CI.
Private packs, source paths, metrics and real writing runs stay outside this checkout.
Keep packs data-only, permissions narrowing, facts separate, and character scopes local.
Scriptorium owns measurements; use a pinned optional bridge or native JSON import.
Run meaningful tests and the public archive audit before publishing changes.
Do not mark voice validated without a scoped owner decision. No consumer mutations
or external publication are authorized by an exported context alone.
